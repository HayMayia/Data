Advanced PowerShell & Manual Setup

VocalBridge is distributed for Windows as an MSIX app package (custom development certificate). Windows 10 (build 1809+) / 11 requires Developer Mode or explicit package registration before first launch.

1
Enable Developer Mode: press Win + I → Privacy & security → For developers (or System → Developer Settings on Windows 10) → toggle Developer Mode ON → confirm Yes.
2
Install the package: download VocalBridge.msixbundle below, double-click it, click Install in the App Installer dialog, then Launch — or find VocalBridge in the Start Menu.
Option A — One-click EXE installer (recommended)

Download VocalBridge.exe and double-click it — the VocalBridge app package is embedded inside, so the Windows install dialog opens automatically. Click Install to finish. (If Windows shows "Windows protected your PC", choose More info → Run anyway.) Advanced CLI mode — pass any package path to install it directly:

.\VocalBridge.exe .\VocalBridge.sideload.msix
Option B — PowerShell (unsigned / sideload packages)

Open PowerShell in the folder containing the package and run:

Add-AppxPackage -Path ".\VocalBridge.msixbundle" -AllowUnsigned
